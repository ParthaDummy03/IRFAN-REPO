# Useful SQL queries for the Taza Food Corner database

The application uses Django ORM for normal database operations. These equivalent SQL examples are useful for understanding the tables in MySQL Workbench or phpMyAdmin. Run them after `python manage.py migrate` and `python manage.py seed_demo`.

## 1. Show all menu items with their category

```sql
SELECT p.id, p.name, c.name AS category, p.price, p.unit_label, p.is_featured
FROM store_product AS p
INNER JOIN store_category AS c ON p.category_id = c.id
WHERE p.is_available = 1
ORDER BY c.sort_order, p.name;
```

## 2. Show featured products on the home page

```sql
SELECT id, name, price, unit_label
FROM store_product
WHERE is_available = 1 AND is_featured = 1
ORDER BY name;
```

## 3. Show active outlets with phone numbers

```sql
SELECT name, area, address, phone, opening_hours, latitude, longitude
FROM store_outlet
WHERE is_active = 1
ORDER BY name;
```

## 4. Show an order with its customer / outlet details

```sql
SELECT o.order_number, o.customer_name, o.phone,
       o.fulfilment, o.status, o.payment_status,
       o.subtotal, o.delivery_fee, o.discount, o.total,
       outlet.name AS outlet_name
FROM store_order AS o
LEFT JOIN store_outlet AS outlet ON o.outlet_id = outlet.id
ORDER BY o.created_at DESC;
```

## 5. Show all items inside an order

```sql
SELECT o.order_number, i.product_name, i.unit_price,
       i.quantity, (i.unit_price * i.quantity) AS line_total
FROM store_orderitem AS i
INNER JOIN store_order AS o ON i.order_id = o.id
WHERE o.order_number = 'REPLACE_WITH_ORDER_NUMBER';
```

## 6. Show valid active coupon codes

```sql
SELECT code, description, discount_type, discount_value, minimum_subtotal
FROM store_coupon
WHERE active = 1
ORDER BY code;
```

The `store_*` table names are generated by Django from the `store` application label. Django migrations create these tables; do not manually create them if the migration command has already been run.
